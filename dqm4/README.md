# モンスターズ4 配合検索（準備版）

現在のモンスターズ3アプリの画面・検索・折りたたみ・配合計画を基にした4用の土台です。
同じリポジトリの `dqm4/` に追加しているため、3用のファイルは変更していません。

## 使える機能

- モンスター検索、名前・図鑑番号・ランク・系統での並び替え
- 登録済み配合の作り方・逆引き配合先、生息地、出典リンク
- 配合ルートの展開、素材数、チェック・進捗の端末保存
- スキル画面と属性・状態異常別おすすめ編成画面（未登録時は確認待ちを表示）
- ホーム画面追加、初回オンライン利用後のオフライン閲覧

## 登録範囲と根拠

全358体は発売前の登場確認一覧であり、発売後の全図鑑を意味しません。
詳細未公開の197体は名前と系統を登録し、図鑑番号・ランク・配合などは未確認です。
仮称を含む一覧のため、正式名称未確認のものは表示で明示します。
特性名はS/L別に登録していますが、一覧に習得レベルがないため未確認と表示します。
おすすめ編成・スキル進化条件・卵からの入手は未登録です。
攻略文の説明文・画像は転載せず、名称・数値・組み合わせと出典URLを登録します。

## 収集とDB更新

- `pip install lxml`
- `python3 dqm4/scripts/update_database.py`
- `python3 dqm4/scripts/build_data.py`

GitHub Actionsの **Update DQM4 database** → **Run workflow** でも実行できます。
更新は一覧ページの内容を解析してJSONのDBを作り、配合先の逆引きを生成する方式です。
3用のDBとは独立しており、更新対象は `dqm4` 内だけです。
一覧の件数不一致や未知の親モンスターがあれば、更新を失敗させて既存データを保護します。
一覧ページの構造が変わった場合は収集スクリプトの調整が必要です。

## データの追加

1. `monsters.source.json` に固有の `id`、名前と確認済み項目を追加。
2. `recipes` に `type`、`parents`、`sourceUrl` を追加。親はすべてモンスター一覧に登録。
3. `python3 dqm4/scripts/build_data.py` を実行し、生成された `data.json` もコミット。
4. スキルは `skills.json` の `skills` に3用と同じ形式で登録。
5. おすすめ編成は `recommendations.json` の `teams` に登録。

おすすめ編成の形式：
```json
{"target":"fire","strategy":"stable","title":"火の編成","reason":"編成の根拠","sourceUrl":"https://example.com/source","members":[{"name":"登録済みモンスター名","role":"攻撃","skills":["確認済みスキル名"],"reason":"採用理由"}]}
```

属性・状態異常のキーは `index.html` のテーマ、方針は `stable` / `power` / `control`。
一覧・公開済み詳細の取得は自動収集スクリプトに対応しています。おすすめ編成は確認したデータを追加する方式です。
公開URLは既存Pages設定がこのリポジトリのルートを公開する場合、末尾が `/dqm4/` です。
キャッシュ更新時は `index.html`、`app.js`、`sw.js` のバージョンをそろえて更新します。

## ローカル確認

リポジトリのルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/dqm4/` を開きます。
